#### Fixed `Unsupported attribute` errors for `values.*` inputs that `autoinclude` overrides

<<<<<<< HEAD:docs/src/data/changelog/v1.1.3/autoinclude-values-placeholder.mdx
Fixes an issue where unit inputs referencing undefined `values.*` attributes failed HCL decoding before autoinclude inputs could override them. When a sibling autoinclude is present, decoding now defers those attribute errors to the autoinclude merge, which overrides the affected inputs as expected.
=======
A unit input referencing a `values.*` key that the unit's values file doesn't define no longer fails with `Unsupported attribute` when an `autoinclude` block supplies that input. The autoinclude value is applied as intended.
