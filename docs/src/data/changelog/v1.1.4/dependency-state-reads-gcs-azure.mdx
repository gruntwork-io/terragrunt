#### Read dependency outputs directly from GCS and Azure state

The `dependency-fetch-output-from-state` experiment can now read dependency outputs directly from GCS and Azure Storage (`azurerm`) state, in addition to S3. This avoids initializing the dependency and running `tofu output` or `terraform output`.

Azure direct reads require the `azure-backend` experiment as well. Unsupported backends and configurations requiring native-only authentication, endpoint, timeout, or Azure customer-provided-key behavior continue to use the native output path.
