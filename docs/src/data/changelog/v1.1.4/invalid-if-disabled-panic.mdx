#### Fixed panic on invalid `if_disabled` value with `include` block

A `generate` block with an invalid `if_disabled` value (e.g. `"true"` instead of `"skip"`, `"remove"`, or `"remove_terragrunt"`) caused a nil pointer panic when the configuration also contained an `include` block. The error was returned correctly when no `include` block was present.

Terragrunt now returns a descriptive error message naming the generate block and the invalid value in both cases, consistent with how invalid `if_exists` values are reported.
