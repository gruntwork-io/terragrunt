#### `include_in_copy` copies the contents of symlinked directories again

In v1.1.4, a directory named in `include_in_copy` that was a symbolic link no longer had its contents copied into the OpenTofu/Terraform working directory, so files behind the link were missing from `.terragrunt-cache`.

Glob patterns rooted at a symlinked directory now expand through the link again, matching the behavior of v1.1.3 and earlier. The same applies to `exclude_from_copy`.
