#### `tg-login` - Signing in to the Gruntwork Developer Portal

The `tg-login` experiment has been added. It enables `terragrunt login`, which signs you in to the Gruntwork Developer Portal.

Running it prints a one-time code and opens your browser to the page that asks for it. Confirm the code there and the CLI receives a token scoped to your organization and files it under your user configuration directory (`~/.config/terragrunt/tokens.json` on Linux). On a machine with no browser, or over SSH, the code and the URL are still on screen and the CLI keeps waiting, so you can approve from another device.

```bash
terragrunt --experiment tg-login login
```

See the [experiment documentation](/reference/experiments/active#tg-login) for what still has to land before it stabilizes.
