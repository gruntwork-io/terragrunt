#### `azure-backend` can set the minimum TLS version on a bootstrapped storage account

Azure interprets an unset minimum TLS version as `TLS1_0`, but Azure services
deprecated `TLS1_0` and `TLS1_1` in August 2025.

With the `azure-backend` experiment enabled, Terragrunt now provisions a new
storage account with a minimum TLS version of `TLS1_2`, and a `minimum_tls_version`
option lets you raise it to `TLS1_3`:

```hcl
remote_state {
  backend = "azurerm"
  config = {
    storage_account_name = "myterragruntstate"
    container_name       = "tfstate"
    key                  = "${path_relative_to_include()}/terraform.tfstate"
    resource_group_name  = "terraform-rg"
    use_azuread_auth     = true
    minimum_tls_version  = "TLS1_2" # or "TLS1_3"
  }
}
```

`TLS1_2` and `TLS1_3` are the only accepted values; the deprecated `TLS1_0`
and `TLS1_1` are rejected.

The setting applies only when Terragrunt creates the account. It is not
reconciled against an account that already exists, so change it in the Azure
portal or CLI for an existing account.
