#### `terragrunt catalog` no longer prints credentials from a repository URL

When a [catalog](/features/catalog) repository URL carried a user name and password or token, such as `https://user:token@example.com/acme/modules.git`, Terragrunt printed the URL as written in the log line that reports the clone, in the error for a repository that failed to load, and on the loading screen of the catalog TUI.

Those messages now show the URL with the user, the password, and query values other than the revision removed. The clone still uses the URL as written, and a local path is shown as it is written.
