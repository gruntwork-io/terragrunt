#### `-destroy=true` is treated like `-destroy`

Terragrunt recognized a destroy only when the argument was exactly `-destroy`. With `-destroy=true`, which OpenTofu and Terraform accept as the same flag, `terragrunt plan -destroy=true` and `terragrunt apply -destroy=true` were not stopped by [`prevent_destroy`](/reference/hcl/attributes#prevent_destroy), and `run --all` did not use the reverse order.

Terragrunt now recognizes `-destroy=<value>` as a destroy when the value is true, parsed the way OpenTofu and Terraform parse boolean flags (`1`, `t`, `T`, `TRUE`, `true` and `True`), whether the argument comes from the command line or from [`extra_arguments`](/features/units/extra-arguments). A false value, such as `-destroy=false`, is not a destroy. The flag is recognized with one dash or two: `extra_arguments` passes `--destroy` and `--destroy=true` to OpenTofu and Terraform as they are written.

`terragrunt apply -destroy=true` is also handled like `terragrunt destroy` where Terragrunt checks the command: the `run --all` confirmation prompt, the check for dependent units and the cleaning of generated stacks.
