#### `exclude-dependency-outputs` strict control

Terragrunt builds the run queue before it reads dependency outputs, so an `exclude` block that reads one can't remove a unit from the `run --all` queue:

```hcl
dependency "vpc" {
  config_path = "../vpc"
}

exclude {
  if      = dependency.vpc.outputs.skip
  actions = ["all"]
}
```

Terragrunt now warns when an `exclude` block reads a dependency. With the new [`exclude-dependency-outputs`](/reference/strict-controls/active#exclude-dependency-outputs) strict control enabled, the warning becomes an error that names the file and the attribute:

```bash
terragrunt run --all --strict-control exclude-dependency-outputs -- plan
```

```text
exclude.if in /path/to/terragrunt.hcl cannot reference dependency outputs under the exclude-dependency-outputs strict control; Terragrunt builds the run queue before it reads them, so declare `feature "skip" { default = false }` and set `if = feature.skip.value` instead
```

Read a [feature flag](/reference/hcl/blocks#feature) instead.
