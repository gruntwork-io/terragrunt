#### Track the files that OpenTofu file functions read

Terragrunt records the files that the built-in file functions read, so [reading-based filters](/features/filter/attributes#reading-based-expressions) select the units that read them without a `mark_as_read` call:

- `file`
- `templatefile`
- `fileset`
- `fileexists`
- the `file*` hash functions, such as `filesha256`

A file read from inside a template counts too.

[`mark_as_read`](/reference/hcl/functions#mark_as_read) remains the way to record a file that only OpenTofu/Terraform reads, such as one passed to a module as an input, or one a [`run_cmd`](/reference/hcl/functions#run_cmd) script reads.
