#### Read GCS dependency outputs directly under service account impersonation

Terragrunt now reads dependency outputs straight from GCS state when the backend impersonates a service account. Until now, `impersonate_service_account`, `GOOGLE_BACKEND_IMPERSONATE_SERVICE_ACCOUNT` or `GOOGLE_IMPERSONATE_SERVICE_ACCOUNT` sent those dependencies through `tofu/terraform output`.

The account, its `impersonate_service_account_delegates` and the `devstorage.read_write` scope match the native GCS backend. `impersonate_service_account = ""` turns impersonation off, as it does natively.
