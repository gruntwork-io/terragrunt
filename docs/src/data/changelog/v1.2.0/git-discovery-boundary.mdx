#### `git-discovery-boundary` - Bound Git-based filter expressions

The new [`git-discovery-boundary`](/reference/experiments/active#git-discovery-boundary) experiment limits Git worktree discovery to the discovery boundary for expressions such as `[main...HEAD]`. It also accepts a dependent-side boundary inside the working directory. In a monorepo with a catalog next to live infrastructure, you can run this from the repository root, and Terragrunt skips catalog units that only parse after they are generated into a stack:

```bash
terragrunt stack run plan --experiment git-discovery-boundary --filter '(./live/)...[main...HEAD]'
```
