#### Git filter combined with another filter no longer drops stack units

When a Git filter (`[A...B]`) that matched a changed `terragrunt.stack.hcl`
was combined with another `--filter` flag (a path, `reading=`, or a
`.terragrunt-filters` entry), the stack and its generated units were silently
dropped from results. The command exited successfully with only the other
filter's matches, which caused CI jobs to plan and apply nothing for a changed
stack. Stack units are now discovered regardless of which other filters are
present.
