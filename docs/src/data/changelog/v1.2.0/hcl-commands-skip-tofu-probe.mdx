#### `hcl format` and `hcl validate` no longer probe for an OpenTofu binary

`hcl format` and `hcl validate` ran the Auto Provider Cache Dir setup at startup, which probed `tofu -version` before any HCL file was read. When the `tofu` found on `PATH` was slow to respond, such as a version-manager shim that resolves or fetches a version on every call, each invocation paid that cost even though neither command ever runs the binary.

Both commands now skip that setup, so they start formatting and validating immediately. Commands that run OpenTofu/Terraform, such as `run`, behave as before.
