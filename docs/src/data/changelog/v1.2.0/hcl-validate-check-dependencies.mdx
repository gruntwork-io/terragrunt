#### `hcl validate` reports dependencies on deleted units

A `dependency` block that points at a deleted or moved unit made `run --all` fail, while `find`, `list` and `hcl validate` still passed. `hcl validate` now fails for each enabled `dependency` block whose `config_path` does not point at a unit or stack configuration, so the problem is caught before a run:

```bash
terragrunt hcl validate
```

Dependencies on units that a stack generates are not checked, as `hcl validate` does not generate stacks. When `run --all` fails because a configuration is missing, the new `missing-dependency-config` tip points at this check. `find` and `list` behave as before.
