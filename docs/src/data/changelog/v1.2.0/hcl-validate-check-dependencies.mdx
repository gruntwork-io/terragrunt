#### `hcl validate` reports dependencies on deleted units

A `dependency` block that points at a deleted or moved unit made `run --all` fail, while `find`, `list` and `hcl validate` still passed. `hcl validate` now fails for each enabled `dependency` block whose `config_path` does not point at a unit or stack configuration, so the problem is caught before a run:

```bash
terragrunt hcl validate
```

`hcl validate` does not generate stacks, so a `dependency` block that points at a unit inside a `.terragrunt-stack` directory fails until you run `terragrunt stack generate`. A `dependency` block that points at the stack directory itself is checked against its `terragrunt.stack.hcl`.

If `run --all` with a Git-based filter such as `--filter '[main...HEAD]'` fails because a `dependency` block points at a unit or stack deleted in that diff, the error now names it and the reference it still exists at, and the new `missing-dependency-config` tip suggests `hcl validate`. `find` and `list` behave as before.
