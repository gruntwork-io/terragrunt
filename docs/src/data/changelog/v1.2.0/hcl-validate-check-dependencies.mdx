#### Check dependency paths with `hcl validate --check-dependencies`

The [`--check-dependencies`](/reference/cli/commands/hcl/validate#check-dependencies) flag (env: `TG_CHECK_DEPENDENCIES`) makes `hcl validate` fail when a `dependency` block, or a path in the `dependencies` block, points at a path without a unit or stack configuration. Each such dependency is reported, so references to deleted or moved units are caught before a run:

```bash
terragrunt hcl validate --check-dependencies
```

`find`, `list`, and `hcl validate` without the flag behave as before. The flag cannot be combined with `--json` or `--show-config-path`.
