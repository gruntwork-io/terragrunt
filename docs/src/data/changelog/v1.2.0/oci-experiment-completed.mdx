#### `oci` experiment completed

`oci://` module sources now work by default. Use them in a `terraform` block's `source`, and in the `unit` and `stack` blocks of a `terragrunt.stack.hcl`. The `--experiment oci` flag and `TG_EXPERIMENT=oci` are no longer needed. Passing either still works and logs a warning. See [OCI registries](/features/units/oci) for the source syntax and authentication.
