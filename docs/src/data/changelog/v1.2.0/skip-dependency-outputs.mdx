#### Skip dependency outputs with `--no-dependency-outputs`

The [`--no-dependency-outputs`](/reference/cli/commands/run#no-dependency-outputs) flag (env: `TG_NO_DEPENDENCY_OUTPUTS`) skips output resolution for every `dependency` block in a run, so Terragrunt does not call `tofu output` on dependencies that may not be applied yet:

```bash
terragrunt run --all --no-dependency-outputs -- validate
```

<Aside type="caution">
  Use this flag with commands that do not read dependency outputs, such as `init` and `validate`. While it is set, inputs that depend on dependency outputs are left unset, so `plan` and `apply` fall back to variable defaults or fail on missing required variables.
</Aside>

Previously gated behind the `optional-dependency-outputs` experiment, the flag no longer requires `--experiment optional-dependency-outputs`.
