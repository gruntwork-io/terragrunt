#### `--discovery-boundary` respected by `stack generate`, `stack run`, and `stack output`

- `stack generate` and `stack run` now honor `--discovery-boundary` and inline `(dir)` graph boundaries, restricting which stacks are discovered and generated.
- Previously, stack commands scanned the entire working directory regardless of the boundary, causing `find_in_parent_folders` errors in monorepos where catalog stacks coexist with live stacks.
- Inline `(dir)` operands override the `--discovery-boundary` flag, matching the precedence used during filter evaluation.
- Multiple disjoint inline boundaries keep the full working-directory scope so no target is silently dropped.
