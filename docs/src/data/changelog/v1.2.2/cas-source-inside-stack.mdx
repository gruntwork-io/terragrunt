#### `cas-source-inside-stack` strict control

A `unit` or `stack` block with `update_source_with_cas` could set a source inside the directory of its own stack file, e.g. a catalog with its stack at the root and its units under `units/`:

```hcl
# catalog/terragrunt.stack.hcl

unit "foo" {
  source                 = "./units/foo"
  update_source_with_cas = true
  path                   = "foo"
}
```

Stack generation copies the stack directory whole. For a `stack "bar"` block with `source = "../catalog"`, the generated stack contained the unit twice, and `run --all` ran both, the copy without the values its stack gives the generated unit:

```text
.terragrunt-stack/bar/.terragrunt-stack/foo
.terragrunt-stack/bar/units/foo
```

Existing support will be retained for v1.x for backwards compatibility, to obey the [Terragrunt 1.0 guarantees](/process/1-0-guarantees#hcl-configurations).

Terragrunt now warns about each such block, pointing at its source:

```text
WARN   Setting the source of a `unit` or `stack` block with `update_source_with_cas` to a directory inside the stack directory is deprecated and will be removed in a future version of Terragrunt.
WARN   Source inside the stack directory
 --> ../catalog/terragrunt.stack.hcl:2:28
  |
2 |   source                 = "./units/foo"
  |                            ^^^^^^^^^^^^^
  |
  = Stack generation copies the directory of this stack file whole, so the
    generated stack contains this unit twice, and `run --all` runs the copy
    too. Move the unit directory out of the directory of this stack file, and
    use `//` in the stack's source to separate the catalog from the stack
    directory.
```

With the new [`cas-source-inside-stack`](/reference/strict-controls/active#cas-source-inside-stack) strict control enabled, each of those blocks is an error instead:

```bash
terragrunt stack generate --strict-control cas-source-inside-stack
```

Move the stack into a subdirectory of the catalog and keep its sources outside that subdirectory. Then use `//` in the stack's source to separate the catalog from the stack directory, e.g. `source = "../catalog//stacks/bar"`. The `cas-source-inside-stack` control is also part of the `deprecated-configs` group.
