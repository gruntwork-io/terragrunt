#### `fileset` matches patterns that are not in canonical form

In v1.2.0 and v1.2.1, `fileset` returned an empty set, with no error, for a pattern with a leading `./` or `/`, or with `//`, `/./` or `../` in it:

```hcl
inputs = {
  # v1.2.0 and v1.2.1: []
  files = fileset("./", "./resources/*.json")
}
```

An input built from that empty set could make OpenTofu/Terraform plan to remove resources.

When a pattern matches no files as written, `fileset` now cleans it as OpenTofu/Terraform do and matches again, so the call above returns `["resources/a.json"]`. Patterns that already returned files return the same files. See [OpenTofu/Terraform built-in functions](/reference/hcl/functions#opentofuterraform-built-in-functions) for how a pattern is cleaned.
