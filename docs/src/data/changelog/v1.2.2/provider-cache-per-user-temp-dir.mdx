#### Provider cache no longer fails when users share a temp directory

With `--provider-cache`, all users on a machine shared one `$TMPDIR/terragrunt` directory, so `init` could fail for anyone except the user who created it:

```
mkdir /tmp/terragrunt/providers/archives-032480544: permission denied
```

On Unix, each user now gets a `$TMPDIR/terragrunt-<uid>` directory that only they can write to. If that directory is unsafe to use, Terragrunt logs a warning that says why and uses a new directory for that run.
