#### Provider cache works for several users sharing a temp directory

With `--provider-cache`, Terragrunt kept lock files and downloaded provider archives in `terragrunt` under the temp directory. After one user created it, `init` could fail for another user sharing that temp directory:

```
mkdir /tmp/terragrunt/providers/archives-032480544: permission denied
```

On Unix, each user now gets `terragrunt-<uid>` in the temp directory, and only that user can write to it. Terragrunt stops with an error if this path is a symlink, belongs to another user, or another user can write to it or to a parent directory without the sticky bit. A Kubernetes `emptyDir` volume mounted at `/tmp` is such a parent. Run `chmod 1777` on its mount point, or set `TMPDIR` to a directory only you can write to.

Windows still uses `%TEMP%\terragrunt`, which is private to each user by default.
