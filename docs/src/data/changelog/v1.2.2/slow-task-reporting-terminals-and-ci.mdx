#### `slow-task-reporting` - One progress line on terminals, log lines in CI

Slow operations now share one progress line, cut to the terminal width. Log lines are written above it:

```text
| Downloading source from git::https://github.com/acme/modules.git?ref=v1.2.0... (12s) +2 more
```

This fixes stale rows when a message was wider than the terminal, `run --all` output mixed into the spinner text, and the spinner drawing over the `terragrunt catalog` TUI.

In CI, with `TERM=dumb`, with `json` logs, and in `terragrunt catalog`, Terragrunt writes INFO log lines instead.

Operations are now reported after 100ms instead of 1 second.

More operations are reported: unit discovery, `dependency` output fetches, provider caching, waits for new remote state resources, `stack generate` fetches, and lock waits.

`terragrunt login` shows the wait for approval the same way, with or without the experiment. If the line cannot be drawn, Terragrunt prints that it is waiting, at every log level.

A failed Git worktree creation no longer logs that it succeeded.

To learn more, see the [experiment documentation](/reference/experiments/active#slow-task-reporting).
