#### `hcl validate --inputs` counts `-var` and `-var-file` values passed as separate arguments

`hcl validate --inputs` reported a required input as missing when `extra_arguments` or the command line set it with the flag and its value as two arguments, such as `"-var", "region=us-east-1"` or `"-var-file", "common.tfvars"`.

`hcl validate --inputs` now counts a `-var` or `-var-file` flag whose value is in the next argument, and the `--var` and `--var-file` spellings.

A `-var` flag with no `NAME=VALUE`, or a trailing `-var` or `-var-file` with nothing after it, now fails validation, as it fails a run.
