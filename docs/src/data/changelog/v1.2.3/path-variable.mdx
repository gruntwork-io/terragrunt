#### `path-variable` experiment adds the `path` variable

Enable the [`path-variable`](/reference/experiments/active#path-variable) experiment to read paths by name: `path.unit`, `path.stack`, `path.download`, `path.include` and `path.read`.

```bash
terragrunt run --all --experiment path-variable -- plan
```
