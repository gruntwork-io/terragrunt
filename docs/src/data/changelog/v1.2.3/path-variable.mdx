#### `path-variable` experiment adds `unit.path`, `stack.path` and the `path` variable

Enable the [`path-variable`](/reference/experiments/active#path-variable) experiment to read paths by name: `unit.path`, `stack.path`, `path.download`, `path.include` and `path.read`.

```bash
terragrunt run --all --experiment path-variable -- plan
```
