#### `run --all` waits on the dependencies of excluded units

When `a` depends on `b`, `b` depends on `c`, and `b` is excluded from the run, `run --all` no longer starts `a` before `c` finishes, and a failure in `c` now stops `a`. This holds however `b` is excluded: [`--queue-exclude-dir`](/reference/cli/commands/run#queue-exclude-dir), a negative [`--filter`](/features/filter), or an [`exclude`](/reference/hcl/blocks/exclude) block.

A dependency cycle that passes only through excluded units now fails with `cycle detected during queue construction`.
