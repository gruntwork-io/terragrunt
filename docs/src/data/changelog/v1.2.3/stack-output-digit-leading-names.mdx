#### `stack output` accepts unit and stack names that start with a digit

`terragrunt stack output 01-network` failed for a unit named `01-network`, as did any address with a unit or stack name that starts with a digit:

```
ERROR invalid output address "01-network": :1,1-3: Variable name required; Must begin with a variable name.
```

`stack output` now reads each name in the address as written, so `01-network`, `01-network.id` and `platform.01-network.id` return the matching outputs.
