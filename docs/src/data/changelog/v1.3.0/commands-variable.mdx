#### `commands-variable` — Read the lists of commands by name with the `commands` variable

Four functions, e.g. `get_terraform_commands_that_need_vars()`, return the lists of OpenTofu/Terraform commands that accept a set of flags. Enable the [`commands-variable`](/reference/experiments/active#commands-variable) experiment to read them by name: `commands.accept_vars`, `commands.accept_locking`, `commands.accept_input`, and `commands.accept_parallelism`.

```hcl
terraform {
  extra_arguments "retry_lock" {
    commands  = commands.accept_locking
    arguments = ["-lock-timeout=20m"]
  }
}
```

```bash
terragrunt run --all --experiment commands-variable -- plan
```

The functions keep their behavior. See the [`commands` variable reference](/reference/hcl/variables/commands/).
