name: print
path: info/print
category: configuration
sidebar:
  order: 1200
description: Print out a short description of Terragrunt context.
usage: |
  Outputs a JSON object with contextual information such as the configuration file path, current working directory, cache download location, IAM role (if any), the binary used to run OpenTofu/Terraform, and the command being executed.
examples:
  - description: Print out information about the current context of Terragrunt.
    code: |
      $ terragrunt info print
      {
        "config_path": "/example/path/terragrunt.hcl",
        "download_dir": "/example/path/.terragrunt-cache",
        "iam_role": "",
        "terraform_binary": "tofu",
        "terraform_command": "print",
        "working_dir": "/example/path"
      }

<Before version="v1.2.0">

With `--all`, each unit's JSON object is indented over several lines, one object after another, and every unit reports the root's `download_dir`.

</Before>

<Since version="v1.2.0">

With `--all`, each unit is written on one line, so the output is JSON Lines and a reader can take it a line at a time. Each unit reports the context `run --all` gives it, including the `download_dir` it caches into:

```bash
terragrunt info print --all | jq -c '{config_path, download_dir}'
```

</Since>
