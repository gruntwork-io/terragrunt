## Signing in

`login` uses the OAuth 2.0 Device Authorization Grant ([RFC 8628](https://datatracker.ietf.org/doc/html/rfc8628)). Running it prints a one-time code and opens your browser to the portal's approval page.

## Credentials

Terragrunt keeps one credential per organization, in `terragrunt/tokens.json` under your user configuration directory:

- Linux: `$XDG_CONFIG_HOME/terragrunt/tokens.json`, or `~/.config/terragrunt/tokens.json` when `XDG_CONFIG_HOME` is unset
- macOS: `~/Library/Application Support/terragrunt/tokens.json`
- Windows: `%AppData%\terragrunt\tokens.json`
