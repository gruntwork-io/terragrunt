Skip the `.terragrunt-cache` copy and run a unit in place.

### `no-dot-terragrunt-cache` - What it does

By default, Terragrunt copies all OpenTofu/Terraform source into a `.terragrunt-cache` directory before running any commands. When `terraform.no_dot_terragrunt_cache = true` is set in `terragrunt.hcl` and this experiment is enabled, Terragrunt skips the copy and runs directly from the unit directory. Relative local module paths resolve relative to the unit directory, so they work as written, and editors and language servers can read the files directly.

Because the unit runs in place, anything a run produces is written into the unit directory and stays there: `generate` blocks, the `.terraform` directory, the `.terraform.lock.hcl` lock file, and OpenTofu/Terraform state for a local backend. Add the generated files you do not want to commit to your `.gitignore`.

Like the other `terraform` block attributes, `no_dot_terragrunt_cache` is merged through `include`. A root configuration found with `find_in_parent_folders()` can set it once for every unit that includes it, and a unit can override it in its own `terraform` block.

This only applies when no source is configured. If a source is set (via the `terraform.source` attribute or the `--source` CLI flag), Terragrunt returns an error, because a source has to be fetched into the cache directory and cannot be run in place.

```hcl
terraform {
  no_dot_terragrunt_cache = true
}
```

Enable the experiment with:

```bash
terragrunt apply --experiment no-dot-terragrunt-cache
```

### `no-dot-terragrunt-cache` - How to provide feedback

Provide your feedback on the [no_dot_terragrunt_cache option](https://github.com/gruntwork-io/terragrunt/issues/6199) issue.

### `no-dot-terragrunt-cache` - Criteria for stabilization

To stabilize this feature, the following need to be resolved, at a minimum:

- [ ] Validate behavior with `before_hook` and `after_hook` blocks that reference relative paths.
- [ ] Validate behavior with `generate` blocks that write into the working directory.
- [ ] Gather community feedback on edge cases.
