Signing in to the Gruntwork Developer Portal from the CLI, so an admin can define a catalog in the portal alongside the one local HCL names.

### `tg-login` - What it does

<PortalCatalogBeta campaign="tg-login-experiment" />

Adds the `terragrunt login` command, which signs you in to the Gruntwork Developer Portal using the OAuth 2.0 Device Authorization Grant ([RFC 8628](https://datatracker.ietf.org/doc/html/rfc8628)).

While the `tg-login` experiment is active, `terragrunt catalog` automatically discovers repositories your organization has registered in the Gruntwork Developer Portal as part of your catalog.

### `tg-login` - How to enable it

```bash
# Via CLI flag
terragrunt --experiment tg-login login

# Via environment variable
export TG_EXPERIMENT=tg-login
terragrunt login
```

Without the experiment, `terragrunt login` is still listed in `--help` and refuses to run, naming the experiment it needs. `terragrunt catalog` stops reading the portal too, so dropping the flag returns it to the `catalog` block alone, whether or not a credential from an earlier login is still on disk.

### `tg-login` - How to provide feedback

Provide your feedback in the [`tg-login` GitHub Discussion](https://github.com/gruntwork-io/terragrunt/discussions/7118).

### `tg-login` - Criteria for stabilization

To transition the `tg-login` feature to a stable release, the following must be addressed, at a minimum:

- [x] `terragrunt login` completes the device flow and reports the signed-in user and organization.
- [x] On a headless or SSH session, the CLI prints the URL and code to open on another device, and login still completes.
- [x] The CLI stores the token so it survives between commands and expires on its own.
- [x] `terragrunt catalog` browses and scaffolds from the portal-defined catalog as it does from a local one.
- [x] A user who is not signed in still gets a catalog from local configuration.
- [x] A user with no catalog configured anywhere gets guidance on setting one up.
- [x] Test coverage for login and catalog that does not need a live portal.
- [ ] Documentation for login and catalog setup.
- [ ] Completion of the private beta in the Gruntwork Developer Portal.
