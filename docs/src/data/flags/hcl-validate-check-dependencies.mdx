---
name: check-dependencies
description: Check that every dependency points at a Terragrunt configuration.
type: bool
env:
  - TG_CHECK_DEPENDENCIES
since: "v1.2.0"
---

When enabled, Terragrunt checks that each unit's `dependency` blocks (except disabled ones) and `dependencies` paths point at a unit or stack configuration. It reports every one that does not, then exits with an error.

This catches references to units that were deleted or moved, which would otherwise fail only when the unit runs.

`hcl validate` does not generate stacks. If a dependency points at a unit that a stack generates, run `terragrunt stack generate` first.

This flag cannot be combined with `--json` or `--show-config-path`.

Example:

```bash
terragrunt hcl validate --check-dependencies
```
