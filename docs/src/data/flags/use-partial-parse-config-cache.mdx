<Aside type="caution">
**Deprecated**: The `--use-partial-parse-config-cache` flag is deprecated and will be removed in a future version of Terragrunt. Terragrunt no longer has a partial parse cache for it to enable, so the flag has no effect and can be removed from your commands.

To find commands that still pass it, enable the [`use-partial-parse-config-cache`](/reference/strict-controls/active#use-partial-parse-config-cache) strict control, which turns its warning into an error.
</Aside>
