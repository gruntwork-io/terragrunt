The `remote_state` block configures the backend that stores a unit's state, so you can set it once in a file every unit includes. See [State backend](/features/units/state-backend/).

Terragrunt passes the `config` map to the OpenTofu/Terraform `backend` block:

<SideBySide>

```hcl title="terragrunt.hcl"
remote_state {
  backend = "s3"
  config = {
    bucket = "mybucket"
    key    = "path/to/my/key"
    region = "us-east-1"
  }
}
```

```hcl title="Equivalent OpenTofu/Terraform"
terraform {
  backend "s3" {
    bucket = "mybucket"
    key    = "path/to/my/key"
    region = "us-east-1"
  }
}
```

</SideBySide>

Without [`generate`](/reference/hcl/blocks/remote_state#generate), the module needs an empty `backend` block of the same type, e.g. `terraform { backend "s3" {} }`, for Terragrunt to fill in.

### Setting `remote_state` as an attribute

`remote_state` also works as an attribute, so a unit can set it from another file:

```hcl
# terragrunt.hcl

locals {
  common = read_terragrunt_config(find_in_parent_folders("common.hcl"))
}

remote_state = local.common.remote_state
```

### Backend bootstrapping

With `--backend-bootstrap`, or with [`terragrunt backend bootstrap`](/reference/cli/commands/backend/bootstrap), Terragrunt creates the backend's storage before `init` if it's missing, e.g. an S3 bucket, and checks its configuration if it exists. It can do that for the `s3`, `gcs`, and `azurerm` backends.

Otherwise, Terragrunt leaves the storage alone, and `init` fails if the storage doesn't exist. [`disable_init = true`](/reference/hcl/blocks/remote_state#disable_init) makes Terragrunt leave it alone even with `--backend-bootstrap`.

### Encrypting state

The [`encryption`](/reference/hcl/blocks/remote_state#encryption) map needs a `key_provider` key, set to any [key provider OpenTofu supports](https://opentofu.org/docs/language/state/encryption/#key-providers), e.g. `pbkdf2`, `aws_kms`, `gcp_kms`, or `openbao`. Its other keys configure that provider. Terragrunt turns the map into an `encryption` block in the OpenTofu `terraform` block:

<SideBySide>

```hcl title="terragrunt.hcl"
remote_state {
  backend = "s3"
  config = {
    bucket = "mybucket"
    key    = "path/to/my/key"
    region = "us-east-1"
  }

  encryption = {
    key_provider = "pbkdf2"
    passphrase   = get_env("PBKDF2_PASSPHRASE")
  }
}
```

```hcl title="Generated OpenTofu"
terraform {
  backend "s3" {
    bucket = "mybucket"
    key    = "path/to/my/key"
    region = "us-east-1"
  }
  encryption {
    key_provider "pbkdf2" "default" {
      passphrase = "SUPERSECRETPASSPHRASE"
    }
    method "aes_gcm" "default" {
      keys = key_provider.pbkdf2.default
    }
    state {
      method = method.aes_gcm.default
    }
    plan {
      method = method.aes_gcm.default
    }
  }
}
```

</SideBySide>

Two keys in the `encryption` map go to the generated `state` and `plan` blocks instead of the key provider:

- `fallback`: Set to `{ method = "unencrypted" }` to let OpenTofu read state and plan files written before encryption was enabled. Any other value is an error.
- `enforced`: Set to `true` to make OpenTofu error instead of writing unencrypted state or plan files.

Once encryption is configured, OpenTofu refuses to read plaintext state. A unit with existing state therefore needs the fallback for one run, as described under [pre-existing project](https://opentofu.org/docs/language/state/encryption/#pre-existing-project) in the OpenTofu docs:

```hcl
# terragrunt.hcl

remote_state {
  backend = "s3"
  config = {
    bucket = "mybucket"
    key    = "path/to/my/key"
    region = "us-east-1"
  }

  encryption = {
    key_provider = "pbkdf2"
    passphrase   = get_env("PBKDF2_PASSPHRASE")
    fallback     = { method = "unencrypted" }
  }
}
```

Terragrunt adds an `unencrypted` method and points both blocks at it:

```hcl
# backend.tf

  encryption {
    # key_provider and method "aes_gcm" as above
    method "unencrypted" "fallback" {
    }
    state {
      method = method.aes_gcm.default
      fallback {
        method = method.unencrypted.fallback
      }
    }
    plan {
      method = method.aes_gcm.default
      fallback {
        method = method.unencrypted.fallback
      }
    }
  }
```

Run `terragrunt apply` so OpenTofu writes the state back encrypted. Then replace `fallback` with `enforced = true`.
