---
name: get_parent_terragrunt_dir
description: Returns the absolute path of an included file's directory.
configs: [unit, stack]
params:
  - name: name
    type: string
    optional: true
    description: The label of the `include` block whose directory to return. A unit with more than one `include` block needs it. In the included file, it has no effect.
returns: string
examples:
  - description: When `/home/me/infra/prod/mysql/terragrunt.hcl` includes this file.
    code: |
      # root.hcl

      locals {
        root_dir = get_parent_terragrunt_dir() # "/home/me/infra"
      }
---

import FileTree from '@components/vendored/starlight/FileTree.astro';

A file that many units include can use `get_parent_terragrunt_dir` to point every unit at a file next to it, however deep the unit is:

```hcl
# root.hcl

terraform {
  extra_arguments "common_vars" {
    commands = ["plan", "apply"]
    arguments = [
      "-var-file=${get_parent_terragrunt_dir()}/common.tfvars",
    ]
  }
}
```

<FileTree>

- root.hcl
- **common.tfvars**
- app1
  - terragrunt.hcl
- tests
  - app2
    - terragrunt.hcl

</FileTree>

Without an `include` block, it returns the unit's directory, like [`get_terragrunt_dir`](/reference/hcl/functions/get_terragrunt_dir).

A unit with more than one `include` block passes the label of the one to use:

```hcl
# prod/mysql/terragrunt.hcl

include "root" {
  path = find_in_parent_folders("root.hcl")
}

include "region" {
  path = find_in_parent_folders("region.hcl")
}

terraform {
  source = "${get_parent_terragrunt_dir("root")}/modules//mysql"
}
```
