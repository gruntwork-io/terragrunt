  - name: accept_vars
    type: list(string)
    configs: [unit, stack]
    description: |
      The commands that accept `-var` and `-var-file`: `apply`, `console`, `destroy`, `import`, `plan`, `push`, and `refresh`.

    example: |
      # terragrunt.hcl
      terraform {
        extra_arguments "common_vars" {
          commands  = commands.accept_vars
          arguments = ["-var-file=${get_terragrunt_dir()}/../common.tfvars"]
        }

<Aside type="tip" title="Experimental">
  The `commands` variable needs the [`commands-variable`](/reference/experiments/active#commands-variable) experiment. Enable it with `--experiment commands-variable` or `TG_EXPERIMENT=commands-variable`. Without the experiment, a reference to `commands` fails with an error.
</Aside>

Each attribute of `commands` is a list of the OpenTofu/Terraform commands that accept one set of flags. Use an attribute as the `commands` of an [`extra_arguments`](/reference/hcl/blocks/terraform#extra_arguments) block or of a [hook](/reference/hcl/blocks/terraform#before_hook):

```hcl
# terragrunt.hcl
terraform {
  before_hook "notify" {
    commands = commands.accept_locking
    execute  = ["echo", "This command locks the state"]
  }
}
```

`commands` has the same value in a unit, in a file that the unit includes or reads, in a `terragrunt.values.hcl` file, and in a `terragrunt.stack.hcl` file.
