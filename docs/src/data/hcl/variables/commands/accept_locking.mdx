import { Aside } from '@astrojs/starlight/components';

<Aside type="tip" title="Experimental">
  `commands.accept_locking` needs the [`commands-variable`](/reference/experiments/active#commands-variable) experiment. Enable it with `--experiment commands-variable` or `TG_EXPERIMENT=commands-variable`. Without the experiment, `commands` is not defined.
</Aside>

`commands.accept_locking` holds these commands: `apply`, `destroy`, `import`, `plan`, `refresh`, `taint`, and `untaint`.

It has the same value as [`get_terraform_commands_that_need_locking()`](/reference/hcl/functions/get_terraform_commands_that_need_locking).
