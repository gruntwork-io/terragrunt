import { Aside } from '@astrojs/starlight/components';

<Aside type="tip" title="Experimental">
  `commands.accept_parallelism` needs the [`commands-variable`](/reference/experiments/active#commands-variable) experiment. Enable it with `--experiment commands-variable` or `TG_EXPERIMENT=commands-variable`. Without the experiment, `commands` is not defined.
</Aside>

`commands.accept_parallelism` holds these commands: `apply`, `plan`, and `destroy`.

It has the same value as [`get_terraform_commands_that_need_parallelism()`](/reference/hcl/functions/get_terraform_commands_that_need_parallelism).
