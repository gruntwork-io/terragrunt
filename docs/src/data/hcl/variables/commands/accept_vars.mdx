import { Aside } from '@astrojs/starlight/components';

<Aside type="tip" title="Experimental">
  `commands.accept_vars` needs the [`commands-variable`](/reference/experiments/active#commands-variable) experiment. Enable it with `--experiment commands-variable` or `TG_EXPERIMENT=commands-variable`. Without the experiment, `commands` is not defined.
</Aside>

`commands.accept_vars` holds these commands: `apply`, `console`, `destroy`, `import`, `plan`, `push`, and `refresh`.

It has the same value as [`get_terraform_commands_that_need_vars()`](/reference/hcl/functions/get_terraform_commands_that_need_vars).
