Yes. Terragrunt is an IaC orchestration tool built for both [OpenTofu](https://opentofu.org) and Terraform. Where OpenTofu/Terraform is the execution engine, Terragrunt is the orchestration and configuration layer for running IaC at scale: it treats OpenTofu/Terraform modules as versioned, reusable infrastructure patterns and deploys them consistently across environments. [Terragrunt Scale](/terragrunt-scale) likewise supports Terragrunt, OpenTofu, and Terraform.
