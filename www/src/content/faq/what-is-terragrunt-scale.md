[Terragrunt Scale](/terragrunt-scale) is a Terragrunt-native, SCM-hosted or self-hosted CI/CD pipeline including patching and drift management, built by the creators of Terragrunt. It is cloud agnostic and supports all clouds, and it automates Terragrunt workflows across teams, repositories, environments, and cloud accounts. It includes three products: Pipelines (a secure GitOps CI/CD pipeline built for Terragrunt, where plans run when a pull or merge request is opened and applies run on merge), Drift Detection (scheduled and on-demand scans that open a PR/MR when deployed cloud resources no longer match your IaC), and Patcher (automated dependency updates for OpenTofu/Terraform modules and Terragrunt units/stacks). All operations run inside your own runners and repositories using standard GitHub Actions or GitLab CI pipelines.
